# 우리집 (Family Hub)

가족 일정 · 할일 · 아이 숙제 · 칭찬/벌점을 한 곳에서 관리하는 웹앱입니다.

가족이 각자 폰에서 쓰고, 한 사람이 바꾸면 다른 사람 화면에 바로 반영됩니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

처음 받아서 쓰는 경우라면 서버 연결 정보가 필요합니다. `.env.example` 을 복사해
`.env.local` 로 만들고 Supabase 값을 채우세요 ([CLAUDE.md](CLAUDE.md) 9번 항목).

## 로그인이 두 단계인 이유

```
1단계  가족 계정 (이메일+비밀번호)  ─ 기기마다 딱 한 번
2단계  누구세요 (얼굴 고르기)        ─ 앱을 열 때마다
```

가족이 계정 **하나**를 같이 씁니다. 아이가 이메일·비밀번호를 외울 필요가 없도록
나눈 것입니다. 어른이 아이 폰에 1단계를 한 번 해 주면, 그 뒤로 아이는 얼굴만
누르면 됩니다.

- **아이**(비밀번호 없음) — 앱을 열면 바로 들어갑니다
- **부모**(비밀번호 있음) — 얼굴은 기억하되 숫자 4자리를 다시 넣습니다.
  아이가 부모 폰을 집어들어도 부모 권한이 따라오지 않게 하려는 것입니다

부모 초기 비밀번호는 **0000** 입니다. 설정에서 바꾸세요.

## 핸드폰에서 열기

이 앱은 핸드폰에서 쓰는 걸 기준으로 만들었습니다.

1. PC 에서 `npm run dev` 를 켜 둡니다
2. **핸드폰을 PC 와 같은 네트워크(같은 공유기)에 연결합니다**
3. 핸드폰 브라우저에서 터미널에 찍히는 `Network:` 주소를 엽니다
   (예: `http://192.168.0.10:5173` — 주소는 PC 마다 다릅니다)

### 홈 화면에 추가하면 앱처럼 열립니다

- **아이폰(사파리)**: 공유 버튼 → `홈 화면에 추가`
- **안드로이드(크롬)**: 오른쪽 위 ⋮ → `홈 화면에 추가`

주소창 없이 전체 화면으로 열리고, 아이콘도 따로 붙습니다.

### 핸드폰에서 안 열릴 때

회사 와이파이처럼 기기끼리 통신을 막아 둔 네트워크에서는 접속이 안 됩니다.
이럴 때는 이렇게 해 보세요.

- 집 공유기에서 해 보기 (가장 확실합니다)
- 핸드폰 핫스팟을 켜고 PC 를 거기에 연결하기
- PC 방화벽에서 5173 포트 열기 (관리자 권한 PowerShell):

```powershell
New-NetFirewallRule -DisplayName "family-hub dev (5173)" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow
```

PC 를 켜 두지 않고 쓰고 싶다면 아래 '인터넷에 올리기'를 보세요.

## 인터넷에 올리기 (PC 없이 쓰기)

서버가 필요 없는 앱이라 정적 호스팅에 그대로 올라갑니다.

```bash
npm run build   # dist/ 폴더가 만들어집니다
```

`dist/` 폴더를 통째로 올리면 끝입니다. **어느 호스팅이든, 도메인 최상위든
하위 경로든 그대로 동작합니다.** 그래서 이렇게 맞춰 뒀습니다.

- `vite.config.ts` 의 `base: './'` — 자원을 상대 경로로 뽑습니다
- 주소에 `#` 을 쓰는 해시 라우팅 — 서버 설정 없이도 새로고침이 됩니다

올릴 수 있는 곳 (전부 무료, 계정 필요):

| 서비스 | 방법 |
| --- | --- |
| Netlify | 로그인 후 사이트 만들기 → `dist` 폴더 드래그 |
| Vercel | `npx vercel --prod` (브라우저로 로그인) |
| Cloudflare Pages | 대시보드 → Direct Upload → `dist` 드래그 |
| GitHub Pages | 저장소에 푸시 → Settings → Pages |

올린 주소를 핸드폰에서 열고 `홈 화면에 추가` 하면 PC 가 꺼져 있어도 쓸 수 있습니다.

> ⚠️ **올릴 때 서버 연결 정보를 같이 넣어야 합니다.** 빌드할 때 필요합니다.
> GitHub Pages 를 쓴다면 저장소 → Settings → Secrets and variables → Actions 에
> `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 두 개를 등록하세요.
> 다른 호스팅이라면 그쪽 환경변수 설정에 같은 이름으로 넣으면 됩니다.
> 빠뜨리면 '서버 연결 정보가 없어요' 화면만 나옵니다.

### 올리기 전에 알아 둘 것

- **주소를 아는 사람은 누구나 열 수 있습니다.** 다만 가족 계정 이메일·비밀번호가
  없으면 로그인 화면에서 더 들어오지 못합니다. 우리 가족 데이터는 보이지 않습니다.
- 브라우저에 실려 나가는 Supabase 키는 **공개용 키**라 노출돼도 괜찮습니다.
  실제 보호는 서버의 RLS 정책이 합니다. `service_role` 키는 절대 쓰지 마세요.
- `public/_redirects` 는 Netlify 에서 새로고침 404 를 막는 파일입니다. 지금은
  해시 라우팅이라 없어도 되지만, 나중에 주소에서 `#` 을 빼고 싶어질 때를 위해
  남겨 뒀습니다.

처음 열면 **예시 가족**(엄마 / 아빠 / 첫째 / 둘째)이 들어 있습니다.
`설정` 탭에서 실제 가족 이름과 얼굴로 바꿔서 쓰세요.

- 부모(엄마/아빠)의 초기 비밀번호는 **0000** 입니다. 설정에서 바꿀 수 있습니다.
- 아이는 비밀번호 없이 얼굴만 누르면 들어갑니다.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| 📅 일정 | 가족 달력. 날짜를 누르면 그날 일정과 마감인 할일이 보입니다 |
| 🧹 할일 | 집안일. 부모가 만들고, 담당인 사람이 완료 체크합니다 |
| 📚 숙제 | 아이별로 묶어서 봅니다. 사진에서 한 번에 가져올 수 있습니다 |
| ⭐ 포인트 | 칭찬/벌점 이력과 모은 점수, 보상 교환 |
| ⚙️ 설정 | 구성원, 보상, 백업 |

## 사진으로 숙제 등록하기

학원에서 숙제를 사진으로 보내 주는 경우가 많아서, 사진에서 글자를 읽어 숙제
항목으로 만들어 주는 기능이 있습니다. `숙제` 탭 오른쪽 위 **📷 사진** 버튼입니다.

```
사진 고르기  →  글자 읽기  →  결과를 눈으로 확인하고 고치기  →  한 번에 등록
```

- **사진은 저장되지 않습니다.** 브라우저 안에서 글자만 뽑고 바로 버립니다.
  서버로 보내지도 않으니 아이 숙제 사진이 밖으로 나갈 일이 없습니다.
- 읽은 결과는 **한 줄에 숙제 하나**로 잘립니다. `1.` `-` 같은 앞머리 기호는 떼어 냅니다.
- 인식이 완벽하지는 않습니다. 등록 전에 반드시 텍스트를 확인하고 고치는 화면을
  거치게 해 뒀습니다. 인쇄된 글씨는 잘 읽고, 손글씨는 많이 틀립니다.
- 사진 없이 텍스트를 직접 붙여넣어 여러 개를 한 번에 등록할 수도 있습니다.

처음 한 번은 한글 인식 데이터(약 10MB)를 내려받느라 시간이 걸립니다. 그 다음부터는
브라우저가 캐시해 둬서 빠릅니다.

## 포인트가 들어가는 순서

아이가 완료 체크를 해도 점수는 바로 들어가지 않습니다.

```
아이: 다 했어요 체크  →  상태 done
부모: '확인' 버튼     →  상태 confirmed + 칭찬 점수 지급
```

점수를 잘못 줬을 때는 '취소'를 누릅니다. 기록을 지우는 게 아니라 반대 점수가
하나 더 쌓이는 방식이라, 나중에 아이와 이야기할 때 무슨 일이 있었는지 남습니다.

## 데이터는 어디에 저장되나요

**Supabase** 서버에 저장됩니다.

- 가족 모두의 기기에서 같은 내용이 보입니다.
- 엄마가 숙제를 올리면 아이 화면에 **새로고침 없이** 바로 뜹니다.
- 폰을 바꾸거나 브라우저 데이터를 지워도 내용이 남습니다.

### 지울 때 조심할 것

`설정 > 데이터 보관` 의 **백업 불러오기**와 **샘플 데이터로 되돌리기**는
가족 **모두의** 기기에서 내용을 없앱니다. 내 폰에서만 지워지는 게 아닙니다.

**백업 내려받기**는 그대로 두었습니다. 서버가 보관해 주지만, 큰 실수를 되돌릴
길은 있는 게 낫습니다.

## 명령어

```bash
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm run lint     # 린트
```

## 폴더

```
src/
  pages/        탭 하나에 파일 하나
  features/     도메인 로직 (events, tasks, points, members, auth)
  components/   여러 곳에서 쓰는 UI
  lib/          데이터 계층(db), 날짜 계산(date), 권한(permissions)
  types/        공용 타입
```
